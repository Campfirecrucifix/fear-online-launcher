FEAR Online Community Launcher v1.0.1

Play with your Steam friends - no servers, no port forwarding, nobody sees anyone's IP.

HOW TO PLAY TOGETHER (in this order):
 1. HOST clicks HOST and sends the invite code (already copied) to friends.
 2. HOST logs in (any name/password), picks a channel, clicks HOST GAME and creates a room. Don't press START yet.
 3. FRIENDS paste the code and click JOIN (or Steam friends list > Join Game), log in and pick the SAME channel.
 4. FRIENDS click GAME ROOM LIST and double-click the host's room.
 5. When EVERYONE is shown in the room: everyone clicks READY, then the host clicks START.

NEW in v1.0.1: Demolition and the other round modes no longer hang on the loading screen.
Soul King is closed for now (its map is missing from the Steam version and kicked everyone).
Back-to-back matches in the same room now work - no restart needed between matches.
